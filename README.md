Overview

This project uses Python web scraping to collect book information from "Books to Scrape" (https://books.toscrape.com/), a website designed for scraping practice.

Features

- Extract book titles
- Collect book prices
- Retrieve book availability
- Extract ratings
- Save scraped data to a CSV file
- Support paginated scraping

Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

Installation

Install the required libraries:

python -m pip install requests beautifulsoup4 pandas

How to Run

Run the Python script:

python web_scraping.py

Output

The scraped book information is saved as a CSV dataset.
